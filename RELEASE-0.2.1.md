Quick Access 0.2.1 is the first public testing build. Android 8.0 or newer is required; compatibility with individual phones and launchers is still being evaluated.

[Download page and installation guide](https://davidjairaj.github.io/quick-access/)

Choose six shortcuts for apps, Camera, the dialler, places, HTTPS websites, Wi-Fi settings or Clock. Choose among eleven button styles and add a still-image home-screen widget that opens the ring. Saved actions support export, restore and Undo.

This APK is signed with a dedicated app key and is not debuggable. It contains no account, analytics, ads or internet permission. The apps opened by shortcuts have their own privacy practices.

All 10 automated action-validation tests and release lint pass. The signed APK passed fresh installation, editing, process restart and reinstall checks on an isolated Android 15 emulator. Earlier emulator checks cover compact layouts, large text, missing-app repair, persistence and widget recovery. Physical-phone performance, battery behaviour and complete TalkBack gesture/audio operation remain unverified.

Download `quick-access-0.2.1.apk`. `SHA256SUMS.txt` contains its checksum. No GitHub account is needed to download.

Keep Android protections enabled. If installation is blocked, report the exact message and phone model. This testing release is not a Play Store listing or a claim of developer verification.

Existing development builds use a different signing key and cannot be updated in place to this release. If you previously received a debug APK, export your actions privately before uninstalling it. Appearance preferences must be set again. This does not affect first-time testers.
