# Quick Access for Android

Six personal shortcuts around one button. This repository hosts the public
download page, testing instructions and signed APK releases.

**[Download and installation guide](https://davidjairaj.github.io/quick-access/)**

Version 0.2.1 is an early test build for Android 8.0 and newer. It is free to
download and use for testing. There is no account or analytics in the app.
Device compatibility and real-phone performance are still being evaluated.

The website lives in `docs/`. APKs and SHA-256 checksums are attached to
[Releases](https://github.com/davidjairaj/quick-access/releases).
This repository does not contain the Android app source.

Send feedback to David through the conversation where you received the link,
or open an issue. GitHub issues are public: do not include personal phone
numbers, addresses, backup files or other private information.
